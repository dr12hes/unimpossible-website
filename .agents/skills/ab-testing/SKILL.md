# Unimpossible ab-testing

Read [the shared evidence and approval contract](../../skill-contract.md) before applying this workflow. Read the relevant site's approved brief; for our own site use [the Unimpossible brief](../../product-marketing.md).

State hypothesis, exact change, primary outcome, meaningful effect and possible harms before analysing. Inventory baseline volume and data quality. A low-traffic site may need qualitative review and honest observational monitoring instead of an A/B test.
If a controlled test is justified, determine allocation, sample/precision assumptions and stopping rule from actual baseline; do not use a universal sample table or fixed seven-day victory rule. Avoid unplanned peeking and multiple-metric winner selection. Keep business significance separate from statistical significance. Confounding changes, migration, query mix and seasonality limit before/after claims. Return insufficient evidence when warranted. No experiment platform or automation is required for a small output review.
