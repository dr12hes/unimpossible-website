# Unimpossible seo-audit

Read [the shared evidence and approval contract](../../skill-contract.md) before applying this workflow. Read the relevant site's approved brief; for our own site use [the Unimpossible brief](../../product-marketing.md).

Check the actual page, canonical, robots/indexing intent and relevant search evidence before copy. Distinguish deliberate staging/private exclusions from live-site defects. Inspect raw HTML and rendered content when the finding requires it; text extraction alone cannot establish missing markup.
Prioritise observed access/rendering failures and missing useful information. Do not enforce a fixed description length, word count, click depth or ranking-position threshold. Describe missing data honestly. Read Google's current snippet guidance for description work: https://developers.google.com/search/docs/appearance/snippet . Google can select a query-dependent snippet; authored copy is not guaranteed to appear. Do not restrict snippets just to force our wording.
