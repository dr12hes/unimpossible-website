# Unimpossible copy-editing

Read [the shared evidence and approval contract](../../skill-contract.md) before applying this workflow. Read the relevant site's approved brief; for our own site use [the Unimpossible brief](../../product-marketing.md).

Identify point edit versus substantive rewrite. Read the surrounding page and site brief. Preserve useful specificity, approved voice, eligibility and material offers. Explain what each proposed edit changes and what it removes; leave good copy unchanged.
Check clarity, accuracy, consistency and audience intent only as far as this task needs. No mandatory seven-pass review, generic length target or rigid stylistic ban overriding customer intent. Compare exact before/after wording. Flag unsupported claims and name the evidence needed; do not polish them into more convincing misinformation.
