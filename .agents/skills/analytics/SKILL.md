# Unimpossible analytics

Read [the shared evidence and approval contract](../../skill-contract.md) before applying this workflow. Read the relevant site's approved brief; for our own site use [the Unimpossible brief](../../product-marketing.md).

Start with the business decision, available sources, coverage dates and known gaps. Reuse Core imports; do not add a tracking vendor by default. Define event meaning, denominator, source, deduplication and matched reporting windows before comparing rates.
Separate CTA click, valid server-accepted enquiry, qualified enquiry and booked/completed conversation. Define qualification with the owner; do not pretend it is instrumented. Avoid personal information in analytics. AI referral requests are not unique visitors, citations or all AI exposure. Record missing/unattributed traffic and bot/internal filtering limits. Check page/query, position and traffic mix where available; sitewide totals cannot establish a description's effect. Suggest collection changes separately for approval.
