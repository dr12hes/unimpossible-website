# Unimpossible copywriting

Read [the shared evidence and approval contract](../../skill-contract.md) before applying this workflow. Read the relevant site's approved brief; for our own site use [the Unimpossible brief](../../product-marketing.md).

Start with audience, problem, substantiated offer, traffic context and intended action. For existing copy, preserve useful voice and limit the edit to scope. Match CTA promises to what the destination actually does: an enquiry request is not a confirmed appointment.
Draft only supported claims; name missing evidence instead of inventing proof, urgency or guarantees. Show exact wording with rationale and tradeoff. Do not import universal clarity uplift percentages or the unverified SavvyCal 3x claim. First-person CTA wording is an optional hypothesis, not a universal winner. Use downstream completion/qualified enquiries rather than button clicks alone.
